# Home Gym App

سامانهٔ مدیریت باشگاه ورزشی برای مدیریت اعضا، مربیان، جلسات تمرین و امور روزمرهٔ باشگاه. رابط کاربری فارسی و راست‌چین است و امکان تغییر زبان به انگلیسی و انتخاب پوسته را هم دارد.

## امکانات

- فضای کاری جداگانه برای مدیر باشگاه، مربی و ورزشکار
- مدیریت اعضا، مربیان، ظرفیت روزانه و برنامهٔ حضور
- ثبت جلسات و تمرین‌ها، پیگیری بسته‌ها و سوابق پرداخت
- تقویم جلالی، کاتالوگ حرکات و ابزارهای پیشرفت تمرینی
- ذخیره‌سازی محلی آزمایشی، با امکان اتصال به Supabase

> در حالت پیش‌فرض، داده‌های نمونه در مرورگر استفاده می‌شوند. برای استفادهٔ چندکاربره، سرویس‌های Firebase و Supabase را پیکربندی کنید.

## پیش‌نیازها

- Node.js نسخهٔ ۲۰ یا جدیدتر
- npm

## اجرا در محیط توسعه

```bash
npm install
cp .env.example .env
npm run dev
```

برنامه به‌صورت پیش‌فرض روی `http://localhost:3000` اجرا می‌شود. پیش از استفاده از ورود Firebase، مقدارهای `VITE_FIREBASE_*` و `FIREBASE_PROJECT_ID` را در فایل محلی `.env` با تنظیمات پروژهٔ خود پر کنید. برای اتصال به Supabase نیز `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را تنظیم کنید؛ در غیر این صورت، برنامه از داده‌های نمونه استفاده می‌کند.

مقدارهای فایل `.env.example` فقط placeholder هستند. کلیدها، فایل‌های service account و فایل محلی `firebase-applet-config.json` را در Git یا GitHub قرار ندهید. برای Firebase Admin در محیط استقرار، از هویت سرویس/اعتبارنامهٔ امن همان پلتفرم استفاده کنید.

## ساخت و اجرا

```bash
npm run build
npm start
```

فرمان `npm run lint` اجرای بررسی TypeScript را انجام می‌دهد.

## پایگاه داده

تعریف‌ها و migrationهای Supabase در پوشهٔ `supabase/` قرار دارند. فایل `supabase/full_schema_setup.sql` برای راه‌اندازی کامل schema و `supabase/seed.sql` برای داده‌های اولیه در نظر گرفته شده است. سیاست‌های RLS و migrationهای افزایشی نیز در `supabase/migrations/` نگهداری می‌شوند.
